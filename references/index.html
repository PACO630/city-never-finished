CONTEXT／思想脈絡

思想脈絡Context

這些想法並不新。從 1961 年的 Jacobs、Habraken、Price，到 1994 年的 Brand、2010 年的 Koolhaas，許多人都問過同樣的問題：城市由誰決定？什麼該留下？這個展覽是我站在這條線上，對高雄提出的回答。

  1. 1961

    Jane Jacobs《偉大城市的誕生與衰亡》

    城市的活力來自街道上反覆發生的日常使用，而不是規劃者畫出的形式。

    → 我的市場論點從這裡出發：該留下的是生活，不是屋頂。

    出現在 02 把屋頂拆了，市場還在 →

  2. 1961

    John Habraken《支撐體》（Supports）

    集合住宅可以分成兩部分：共同的「支撐」由整體決定，每一戶的「填充」由住的人自己決定。

    → 果貿就是這樣：外形是大家的，每扇窗是各家的。我的想像只能停在支撐這一層。

    出現在 03 那不是我的房子 →

  3. 1961 起

    Cedric PriceFun Palace（未建成，與 Joan Littlewood 合作）

    建築不必有完成的樣子，而是一個讓使用者自己重新組合活動的框架。

    → B 情境的可移動攤位來自這個想法。但 Price 把決定權交給使用者，這裡的按鈕只是模擬——真正的決定在街上。

    出現在 05 你會拆嗎？ →

  4. 1972

    黑川紀章中銀膠囊塔

    膠囊原本被設想可以更換，實際生命卻沿著別的路徑展開；2022 年拆解，部分膠囊進入美術館收藏。

    → 沒有按設計劇本更新，並不等於使用停止變化。

  5. 1994

    Stewart Brand《建築如何學習》（How Buildings Learn）

    一棟建築由好幾層組成，外皮、設備、空間配置各自用不同的速度改變。

    → 所以 85 大樓不必二選一：外殼可以慢，裡面可以快。

    出現在 04 85 不能倒 →

  6. 2008

    Giorgio Agamben〈什麼是當代？〉

    真正當代的人，和自己的時代保持一點距離，所以看得見它的暗處。

    → 這個展覽想做的就是這件事：不接受「保存就是好」或「更新就是好」的預設答案。

    出現在 06 城市不等你 →

  7. 2010

    Rem Koolhaas／OMACronocaos，威尼斯建築雙年展

    被列入保存的東西越來越多，保存本身也成了一種改變城市的力量。

    → 這是對我的提醒：主張留下 85，就必須說清楚為什麼是它，而不是全部都留。

    出現在 04 85 不能倒 →

  8. 2014

    MVRDVMarkthal，鹿特丹

    把市場與住宅放進同一棟大型建築，市場被裝進一個強烈的框架裡。

    → 當市場被放進一個框架，哪些活動得到支持，哪些活動需要協商？這是我對自由黃昏市場 B 情境的保留。

每一則都用我自己的話轉述，不是原文引用。箭頭後面是我和這個想法的關係：同意、延伸，或保留。
